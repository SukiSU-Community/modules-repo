# 标定探针（一次性）

`calibration-probe.zip` 不是为了投稿，也不该被扫描器当成投稿 —— 它只是
`AI Budget Calibrate` 这个一次性 workflow 的输入：拿一枚体量对位于真实工作点的包，
真发一次，读出 `credits / neededBytes`。

## 为什么要这个包，而不是随手捏一个小 zip

标定要量的是「把一整个模块包送进模型要花多少钱」。credits 里有一块**固定的系统提示成本**，
与包内文本字节数无关。探针越小，固定成本占比越高，外推出来的字节预算就越小 ——
小探针标出来的预算，上线后会把所有真实包判成 over-budget。

所以这个包的文本量刻意对齐真包实测量级（约 766 KB）。实测：

```
entries 67  unread 0
neededBytes 815065  textClipped 0
```

## 内容为什么这么平淡

全部是可读文本、无外联 URL、无 `/data/adb` 写路径、无 eval、无魔数。静态规则对它 0 命中
（`low auto-approve`）。标定要量的是字节↔花费，一旦探针自己命中规则，读数里就混进了
与字节无关的变量。

## 用完怎么处理

这个目录可以在标定完成后直接删掉；它不进 `pending/`，也不参与索引构建。
